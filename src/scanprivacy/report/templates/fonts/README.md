# Fonts

Bundled so that reports and the site look the same on every machine; the system fonts of a CI runner are not a design decision.

- **Inter** (latin subset, weights 400, 500, 600, 700, and 400 italic), (c) The Inter Project Authors. SIL Open Font License 1.1, see `OFL-Inter.txt`.
- **JetBrains Mono** (latin subset, weights 400, 500), (c) The JetBrains Mono Project Authors. SIL Open Font License 1.1, see `OFL-JetBrainsMono.txt`.

Files come from the `@fontsource/inter` and `@fontsource/jetbrains-mono` 5.3.0 packages. The fonts are separate works under their own licence; the AGPL of this project does not apply to them.
